Privacy Policy

Last updated: 14 September 2026

This policy covers the personal automation applications and tools operated by Kaio Andrade on kaioandrade.com (referred to below as "these applications"). They are private, single-user tools built and used by the account owner. They are not offered as a public service and have no other users.

Who operates these applications

These applications are operated by Kaio Andrade, an individual based in Queensland, Australia. The data controller is the account owner. Contact: contact@kaioandrade.com.

What these applications access

When the account owner authorises an application through Google sign-in, the application receives an access token scoped to the specific permissions the owner approves. Depending on the tool, this may include:

  • Gmail — reading message metadata and content, and sending mail on the owner's behalf.
  • Google Calendar — reading and managing calendar events.
  • Google Drive, Docs and Sheets — reading files used as data sources for the owner's own workflows.
  • Google Contacts — reading contact names and email addresses.

Access is limited to the permissions actually granted. No broader access is requested, and access can be revoked at any time (see below).

How the data is used

Google user data is used for one purpose only: to perform tasks the account owner has asked the application to carry out for themselves — for example summarising the owner's own email, drafting replies, creating calendar events, or reading a spreadsheet the owner has designated. Processing happens locally on the owner's own machine and on infrastructure the owner controls.

What is not done with the data

  • Google user data is never sold, rented or traded.
  • It is never shared with third parties, except where a task the owner explicitly requested necessarily involves another service.
  • It is not used for advertising, profiling, or to train machine-learning models.
  • It is not accessed by any human other than the account owner.
  • It is not transferred to any party for unrelated purposes.

Storage, retention and security

OAuth tokens and any derived data are stored on the owner's own systems and are protected by filesystem permissions and, where applicable, encryption in transit and at rest. Data is retained only for as long as it is useful to the task the owner requested, and is deleted when no longer needed.

Google API Limited Use disclosure

These applications' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The account owner can revoke any application's access at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored token and the application can no longer access that Google account.

Website analytics and cookies

This website does not use advertising or third-party tracking cookies. The contact form collects only the name, email address and message you choose to submit, and uses them solely to reply to your enquiry.

Changes to this policy

If this policy changes, the revised version will be posted at this address with an updated date above.

Contact

Questions about this policy or about data handled by these applications: contact@kaioandrade.com.
